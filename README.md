# Yamagata-inaka.github.io

山形 × 田舎 × 動いた、なぜ？

**https://yamagata-inaka.github.io/**

遊びで作ったカオスなトップページです。まじめなものを見に来た方は、[学習ツール集](https://yamagata-inaka.github.io/study-tools/)へどうぞ。

## できること

- 画面のどこかをタップすると、何かが噴き出します。
- 「カオス度 +1」を押すほど、降ってくるものが増え、色がおかしくなり、ステッカーが勝手に動き出します。
- カオス度の上限は 5 です。それ以上はブレーカーが落ちます（という設定です）。
- 「落ち着く」を押すと元に戻ります。
- OS で動きを減らす設定にしている場合、アニメーションは止まります。

## ネタについて

さくらんぼ、芋煮、コンビニまでの距離、カエル、熊などは、ほぼフィクションです。ページの内容から書いた人の生活を推理しても、たぶん外れます。

## 作り方

HTML ファイル 1 枚だけで動きます。ライブラリもビルドも使っていません。

コードと文章は AI が書き、人間は「カオスにして」と頼んで、動いたものを眺めています。

コードは AI、責任は自分。
